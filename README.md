🎮 Sobre el proyecto

Este proyecto consiste en un pequeño juego web en el que el jugador se enfrenta a la máquina.

Fue creado como práctica para trabajar la lógica, la interacción y la creación de una experiencia sencilla directamente desde el navegador.
